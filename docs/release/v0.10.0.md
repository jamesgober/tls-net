# tls-net v0.10.0 - Simplicity

**Simpler to use, with a few renames.** 0.10.0 came from an audit of the API against how it is actually used: by serve-net, by smtp-net, and by tls-net's own tests. The audit found seven problems, written down in `docs/STABILITY-1.0.md` as S-1 to S-7, and all seven are fixed. Most code needs no change. Every rename and removal is listed in `docs/MIGRATION-0.10.md`.

## Added

- **`TlsStream`** (D-141). A client or server now runs over a `TcpStream`, or any other blocking `Read + Write`, in one call:

  ```rust,ignore
  let mut tls = tls_net::client()?.connect_stream("example.com", tcp)?;
  let mut conn = server.accept_stream(tcp)?;
  ```

  Before this, using a session over a socket meant writing a loop around `step` by hand. Three copies of that loop existed, the longest about 300 lines. For a session made another way (STARTTLS, a pinned identity), `TlsStream::client` and `TlsStream::server` take the session.

  `read` returns `Ok(0)` only after the peer's `close_notify`. A connection that ends without it is an `UnexpectedEof` error carrying `UncleanClose`, so the easy path cannot mistake a truncated response for a complete one (T-17).
- **`TlsError::Transport { kind }`** (`TLS-0047`): the transport under a `TlsStream` failed.

## Changed and removed

| 0.9 | 0.10 |
|---|---|
| `ClientBuilder::new()`, `ServerBuilder::new()` (and `Default`) | `TlsClient::builder()`, `TlsServer::builder()` |
| `server.handshakes_in_progress()`, `server.sni_disagreements()`, `server.version()` | `server.stats().in_progress`, `.sni_disagreements`, `.config_version` |
| `ServerStats::snapshot_version` | `ServerStats::config_version` |
| `ServerReader`, `server.reader()` | `WorkerAcceptor`, `server.worker_acceptor()` |
| `HelloParser::parse(input, &limits)` | `parse_client_hello(input, &limits)` |
| `INCOMING_MIN`, `OUTGOING_MIN` | `MIN_INPUT_BUFFER`, `MIN_OUTPUT_BUFFER` (same values) |

Each change leaves one way to do a thing, with a name that says what it does (D-142).

## Documentation

`docs/API.md` now follows the house format. Every example in it and in the README is compiled as a doctest, so the documentation can no longer drift from the API; most examples also run. Before this release, none of its 85 code blocks was compiled.

## Costs

Nothing changes on an existing path: the removed methods' values come from `stats()`, which reads the same atomics. A `TlsStream` holds an input buffer of `MIN_INPUT_BUFFER` (grown for a larger hello or chain) and an output buffer of `MIN_OUTPUT_BUFFER`. It copies a record's plaintext once when the caller's read buffer is smaller than the record.

## Upgrading from 0.9

- serve-net's TLS test uses `ClientBuilder::new()`; it becomes `TlsClient::builder()`.
- smtp-net uses none of the changed items. Its TLS layer can use `tls_net::MIN_INPUT_BUFFER` where it hard-codes `18_437`.
